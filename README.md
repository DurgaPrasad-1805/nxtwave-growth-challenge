## 🎯 Executive Overview

To acquire 500 students with only ₹2,000, the maximum allowable blended Customer Acquisition Cost (CAC) is **₹4.00**. 
Because paid acquisition on Meta/Google in Indian EdTech costs ₹30–₹60 CPL, this project scraps paid ads entirely and deploys an **in-product organic growth engine** paired with **peer WhatsApp distribution loops**.

### Core Pillars
1. **Interactive Pre-Workshop Asset (`index.html`):** An AI Project Architect that dynamically matches students' engineering branches to customized 60-minute projects and instant ATS-formatted resume bullets.
2. **Built-in Viral Referral Loop ($K = 0.32$):** Post-registration milestone engine that unlocks the *2026 AI Capstone Blueprint & Interview Vault* when a student refers 2 batchmates.
3. **Class Representative (CR) Placement Guilds:** Mobilizing 35 CRs across 20 colleges to broadcast official placement circulars in batch WhatsApp groups.
4. **₹2,000 Budget Deployment:** ₹1,200 for CR performance leaderboards + ₹800 live session attendance raffle.

---

## 🛠️ The Working Growth Asset

The web application is a **dual-mode tool** built with zero external dependencies (pure vanilla HTML5, CSS3, and JavaScript):

### 🎓 1. Student Acquisition View
- **Interactive AI Project Architect:** Students select their engineering branch (CSE, ECE, Mech, Civil, Non-CS) and project domain (Placement Copilot, Document QA, Autonomous Agents, Computer Vision) to view their customized 60-minute project and ATS resume bullet preview.
- **Frictionless 1-Click Registration:** Quick 3-field RSVP (Name, WhatsApp Number, College) generating a unique Ticket ID (`NXW-[NAME]-[RANDOM]`).
- **Viral Referral Engine:** Dynamic referral URL, 1-tap WhatsApp sharing with pre-filled viral copy, and milestone progress tracker with interactive test simulation.

### 📊 2. Growth Operations Console
- **Real-Time Funnel Telemetry:** Live counters for verified registrations, viral $K$-factor, budget burn, and active CR groups.
- **Channel Attribution Breakdown:** Granular metrics tracking reach, conversion rates, and CAC per channel vector.
- **Data Export:** 1-click lead telemetry export to CSV.

## 🚀 Quick Start / Local Setup

Run the application locally without any server dependencies:

```bash
# Clone the repository
git clone https://github.com/DurgaPrasad-1805/nxtwave-growth-challenge.git

# Navigate to project folder
cd nxtwave-growth-challenge

# Open directly in browser
open index.html
```

Or run with Python's built-in HTTP server:

```bash
python3 -m http.server 3000
# Open http://localhost:3000 in your browser
```
